What developers usually want from an installer tool

Stop duplicating configuration

App name, version, source files, destination, registry, shortcuts and languages belong to one InstallerLab project instead of separate EXE and MSI definitions.

Work visually without losing control

Use panels for routine authoring while the FSS project remains visible and editable for review, version control and advanced rules.

Ship a branded installer

Windows installer builder FAQ

Is InstallerLab free?

InstallerLab's main installer creation workflow is free. Optional supporter/PRO activation from US$10 unlocks Portable creation and 21 additional PRO themes for one machine.

Can InstallerLab build both EXE and MSI?

Yes. Setup EXE and MSI use the same InstallerLab project/FSS configuration, so developers do not need to maintain a second MSI definition for the normal workflow.

Do I need to write WiX XML?

Not for the normal visual MSI workflow. InstallerLab prepares the MSI request from your project and uses WiX as the backend.

Can I still edit the installer as text?

Yes. FSS is InstallerLab's editable declarative project format and remains available alongside the visual editor.
