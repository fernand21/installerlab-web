Windows installer builder FAQ

Can InstallerLab build EXE, MSI and Bundle from the same project?

Yes. The FSS remains the project definition while each backend handles its own output format.

Can I migrate from Inno Setup?

InstallerLab v2 includes an ISS → FSS importer for supported script sections. The converted project should be reviewed and analyzed before release.

Do MSI and Bundle require WiX?

Yes. InstallerLab itself can run without WiX, but creating MSI or Bundle packages requires the WiX CLI and the extensions used by the Bundle backend.

Do I need to write WiX XML manually?

Not for normal InstallerLab authoring. The project is defined visually/FSS and translated for the WiX-based backends.
