# InstallerLab — Free Windows Installer Builder

InstallerLab is a **visual Windows installer builder** for developers who want to create **Setup EXE, MSI and Portable packages** without maintaining separate installer projects.

Website: https://fernand21.github.io/installerlab-web/

Download: https://fernand21.github.io/installerlab-web/download/

Documentation: https://fernand21.github.io/installerlab-web/docs/

## Why InstallerLab

- Visual Setup EXE authoring
- MSI generation from the same InstallerLab/FSS project
- Portable packaging workflow
- Editable FSS project format
- 36 installer languages
- 11 free themes + 21 optional supporter/PRO themes
- Registry, shortcuts, file associations, Open With and context-menu integration
- B4J Portable workflow using B4JBuilder and B4JPackager11
- Direct official downloads with SHA-256 hashes and live GitHub Release counters
