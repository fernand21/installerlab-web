# InstallerLab v5.0.0 — Interface Refresh & Maintenance

InstallerLab 5.0.0 focuses on the **application's graphical interface** and small refinements. This release is not intended to introduce a new packaging engine or major new features.

## What's changed

- **Refreshed user interface:** updated the visual presentation of the InstallerLab desktop application.
- **Minor adjustments:** small maintenance and polishing changes.
- **Existing workflows retained:** the established installer and deployment capabilities remain the focus, including projects and formats already supported by earlier versions.

## Existing capabilities

InstallerLab continues to provide its visual FSS-based workflow for Windows deployment, including supported Setup EXE, Portable, MSI, Bundle, Web-to-EXE, Office add-in and QGIS plugin projects, with the applicable project-specific build targets.

## Download

Get the official assets from the **GitHub Releases** section. Files will be attached by the maintainer before publishing this release.

## Notes

This is primarily a **visual update**. The features introduced in v4 and earlier remain part of the product; this release should not be mistaken for a new implementation of them.
