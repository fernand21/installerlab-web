What changes in v2 for Inno Setup users?

Import instead of retyping

The ISS → FSS importer converts supported sections into InstallerLab's project format, giving you a practical migration starting point.

Keep the result editable

FSS is plain text. You can inspect, version and modify the migrated project directly or through the visual editor.

Analyze before packaging

FSS Analyzer helps surface errors, warnings and compatibility issues before the first migrated build.

Generate MSI without a second project

InstallerLab reuses the same FSS when creating the MSI through its WiX backend.

Add a real Bundle when prerequisites matter

The WiX Burn backend can chain prerequisite EXE/MSI packages before the main MSI and produce a single Bundle EXE.

Keep visual authoring available

Routine tasks stay in project panels while advanced rules remain visible in FSS.

Where InstallerLab fits compared with script-first tools

InstallerLab optimizes for

  • Visual authoring for common installer tasks.
  • A lightweight editable FSS project as source of truth.
  • Multiple outputs from one project.
  • Migration from supported ISS sections.
  • Pre-build FSS analysis.
  • Bundle prerequisite chaining through WiX Burn.

InstallerLab does not claim

  • That every Inno Setup feature converts automatically.
  • That FSS and ISS are the same language.
  • That every enterprise packaging scenario is covered.
  • That migration eliminates the need for testing.

Inno Setup migration FAQ

Can InstallerLab import an .iss file?

InstallerLab v2 includes an ISS → FSS importer for supported sections and rules. The converted project should be reviewed before release.

Does InstallerLab replace Inno Setup syntax with FSS?

Yes, the imported project becomes InstallerLab FSS. FSS is InstallerLab's own declarative project format.

Can the imported project create MSI or Bundle?

When the migrated configuration is compatible with those backends, the same FSS can be used for MSI and WiX Burn Bundle builds.

Do I still need to test the installer?

Absolutely. Import and analysis reduce manual work, but real installation and uninstallation testing remain necessary.
