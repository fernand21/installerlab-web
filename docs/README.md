# Sitio de InstallerLab

Este directorio contiene el sitio estático de presentación del proyecto. `index.html` es la portada y `documentacion.html` es la guía independiente.

Cuando se cree el repositorio en GitHub, activa **Settings → Pages** y selecciona **Deploy from a branch**, con la rama principal y la carpeta `/docs`. GitHub publicará `index.html` sin requerir un generador de sitios ni dependencias externas.

Mientras no exista un repositorio público, el enlace de GitHub de la portada se mantiene como texto de estado para evitar apuntar a una URL inexistente.
