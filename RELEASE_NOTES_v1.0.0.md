# InstallerLab v1.0.0 — First Public Release

InstallerLab is a free Windows packaging tool focused on making application distribution visual, practical and easy to maintain.

This is the first public release of InstallerLab.

## Highlights

- **Visual Setup EXE authoring** — select your application folder, main executable and output folder, then build.
- **Visual editor + FSS script** — the visual panels automatically maintain the same InstallerLab project script, while advanced users can edit the FSS directly.
- **MSI from the same project** — generate an MSI from the same InstallerLab/FSS project without maintaining a separate installer definition or writing WiX XML manually.
- **Portable packaging** — supporter/PRO activation unlocks portable creation.
- **B4J Portable workflow** — uses the official B4J toolchain and adds InstallerLab's project-aware launcher/distribution layer.
- **Windows integration** — shortcuts, registry entries, file associations, Open With integration and context-menu commands.
- **Languages** — configure installer languages visually, including the default language and startup selector.
- **Themes and branding** — 11 themes are available free; supporter/PRO activation unlocks 21 additional PRO themes.
- **Installer and cleanup actions** — configure install, run and uninstall behavior from the same project.

## Downloads

Attach the builds that fit your needs to this release:

- **InstallerLab Setup EXE** — recommended for most users.
- **InstallerLab Portable EXE** — run InstallerLab without a traditional installation.
- **InstallerLab MSI** — optional; useful for Windows Installer / managed deployment scenarios.

> The downloadable Portable edition of InstallerLab is separate from the PRO feature that allows InstallerLab to create portable packages for other applications.
