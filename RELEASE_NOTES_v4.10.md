# InstallerLab v4.10 — RTF License Support

InstallerLab v4.10 adds support for using **RTF (Rich Text Format) license documents** in installer projects.

## What's new

- **RTF license/EULA support** has been added.
- Installer projects can now use formatted license documents instead of being limited to plain text.
- RTF licenses can preserve common rich-text formatting such as headings, bold text, alignment and structured legal content.
- The new RTF workflow integrates with InstallerLab's existing project and installer-generation process.
- Existing project types and packaging targets remain compatible.

## License documents

This update is especially useful for projects that include an **EULA, license agreement, terms of use or other formatted legal document**.

Using RTF makes it possible to keep the license text readable and professionally formatted when it is presented to the user during installation.

## Compatibility

InstallerLab v4.10 keeps the capabilities introduced in the v4 line, including Web-to-EXE, Setup EXE, MSI, Bundle, Portable workflows and the existing FSS project system.

## Release status

This GitHub release is created first as a **draft** so the final InstallerLab v4.10 binaries can be attached and reviewed before publication.
